/tg/ Station 13 - Modules - Types — Var Details - Proc Details

techweb_catalogue
/datum/asset/json/techweb_catalogue

Display data for every techweb node and design, shared between the R&D console and the Science Hub app

Vars

design_countHow many designs the last build had, so we know to rebuild if one gets registered
idsThe id of everything in the catalogue, by typepath or name. Kept between builds so live data still matches an older one
needs_buildWhether or not the catalogue needs to be (re)built on next use. Set at first and whenever a node or design changes
node_countHow many nodes the last build had, so we know to rebuild if one gets registered
versionThe number of times the catalogue has been built this round, so the UI knows which build it has

Procs

get_idReturns the id for a typepath or name, giving it the next free one if it doesn't have one yet
get_window_dataSends the catalogue to the user, then returns the url their window loads it from and which build it is
